# Gulnaz & Jake

A tiny static site for gulnazandjake.com.

## GitHub Pages
1. Create a new public GitHub repository (for example `gulnazandjake`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Once the Pages URL works, add `gulnazandjake.com` under Settings > Pages > Custom domain.
6. GitHub will show the DNS records you need to add at your domain registrar. After DNS resolves, enable Enforce HTTPS.

Edit the text directly in `index.html`; the rotating internal memos live in `script.js`.
